🎯 Empirical Measurement Scope Reconciliation & Discrepancy Clarification

Audit Invariant: Zero Measurement Ambiguity

Benchmarks in intrusion detection often present apparently conflicting numbers when measurement scopes are conflated. XRL-IDARS explicitly reconciles its reported figures across isolated microbenchmarks, live streaming burst queues, cold model weights, and heavy stress-test footprints.

⏱️ Latency Scope Reconciliation: ~3.5 ms vs ~35.4 ms

Scope 1: Isolated Model Microbenchmark (Direct Feature Vector)
Single-flow Random Forest inference directly on CPU without packet capture, socket buffers, or thread queue locks: 3,525.08 µs (~3.53 ms) (284 flows/s). Vectorized batch of 100 flows drops to 53.87 µs/flow (18,563 flows/s). Policy execution is 1.95 µs (Cost-Optimal).
Artifact: results/phase2/EXP-P2B-READINESS-AUDIT-CLOSURE-001/latency_reconciliation.json
Scope 2: Streaming Burst Pipeline Queue (End-to-End Packet Stream)
Real-time packet processing under line-rate 1,000-packet burst with packet capture (0.50 µs P50), bidirectional flow assembly (12.89 µs P50), feature extraction (763.72 µs P50), dual-model sequence queuing with thread contention (35,416.18 µs / ~35.42 ms P50), policy evaluation (916.16 µs P50), and safety gate (14.12 µs P50). Total end-to-end flow completion latency: 37,513.87 µs (~37.51 ms P50).
Artifact: results/phase3/EXP-P3-BURST-1000-001/latency_metrics.json

💾 Memory Scope Reconciliation: ~123.2 MB vs 1,049.45 MiB Peak RSS

Scope 1: Quiescent Model Weight Footprint (Cold Process RAM)
Process baseline resident memory required to hold serialized scikit-learn and PyTorch model weights plus flow hash tables in RAM in idle state without network queues: ~123.2 MB total RAM (RF: 117.4 MB, LSTM: 1.2 MB, DQN: 0.4 MB, hash table: 4.2 MB) with 0.2% idle CPU.
Audit: Process initialization memory audit
Scope 2: Peak Stress & Soak Footprint (Continuous Flood & Provenance)
Empirical memory profile during heavy socket flood stress, attack audit tracing, failure injection, and 10,000 soak flows: Start RSS was 163.69 MiB. Transient buffer allocations caused peak RSS to reach 1,049.45 MiB (~1.05 GiB), safely dropping back to 175.74 MiB post-soak. Net permanent growth was only 12.05 MiB (7.36%) over 10,000 flows (zero unbounded memory leaks).
Artifact: results/phase3/EXP-P3K-STRESS-SECURITY-001/resource_metrics.json
