How is the threat score calculated? (click to verify)

Each completed flow is reduced to the frozen R10 feature vector, preprocessed, and scored by the frozen CIC-IDS2017 Random Forest. The score is P(attack); the alert threshold is 0.50. 

raw = [flow_duration_ms, flow_packets_per_s, flow_bytes_per_s,
       packet_length_mean, packet_length_std, syn_count,
       ack_count, rst_count, fin_count, syn_ack_ratio]
score = random_forest.predict_proba(preprocessor.transform(raw))[0]
label = "ATTACK" if score >= 0.50 else "BENIGN"
alert = HIGH if score >= 0.85 else MEDIUM if score >= 0.65 else LOW

Click features on any alert row to see the exact 10 values the model received for that flow. The simulator only supplies packets — it never writes a score; the value comes from the frozen model.

Offline Model Comparison — CIC-IDS2017 (3 seeds, test set)

The Live Monitor serves the per-flow Random Forest. The CIC-IDS2017 LSTM (5-flow sequences) and RF+LSTM fusion are evaluated offline; the mean ± std values come from multi_seed_metrics.json. The 95% bootstrap CI in each cell is computed from the frozen seed-42 test predictions (bootstrap_cis.json) and quantifies test-set sampling uncertainty, not seed variance.
