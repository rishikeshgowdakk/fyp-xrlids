Project Purpose & Scientific Platform Status

Commit: 5989bf4

XRL-IDARS is a research platform for explainable machine learning and reinforcement learning in network security. This interface operates as a Research Evaluation Workbench, surfacing genuine held-out evaluation outputs, formal component verification statuses, and empirical evidence across four benchmark configurations.

Production Safety Invariant: Autonomous production enforcement is strictly NO-GO. The system operates exclusively in an observational monitoring and offline simulation mode. Zero network mutations (iptables, routing, socket drops) are permitted.
