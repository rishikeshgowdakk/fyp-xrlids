System Overview
XRL-IDARS inspects network traffic flows through an integrated multi-tier pipeline: deterministic rules catch protocol violations and volumetric bursts, a trained Random Forest classifier performs primary flow inference, TreeSHAP computes genuine local feature attributions for each prediction, and a Deep Q-Network recommends mitigation actions under a deterministic advisory safety gate. Replayed traffic streams held-out benchmark datasets through the live pipeline to demonstrate real-time response.
