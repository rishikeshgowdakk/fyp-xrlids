# CLAIMS REGISTRY

Every major project claim gets a unique ID, linked evidence, and a status. This exists to
prevent accidental unsupported claims. If a claim has no evidence path, its status is Pending.

Status values: `VERIFIED` · `NOT REPRODUCED` · `PENDING` · `RETIRED`

## Format

```text
CLAIM-00X
"<claim text>"
Research question: RQ<n>
Evidence: EXP-<...> / results/<path>
Status: VERIFIED | NOT REPRODUCED | PENDING | RETIRED
Evidence path: <results/... / experiment card / commit>
Last checked: <date>
```

## Claims that must NOT be made

These statements are explicitly **unsupported**, refuted, or outside the validated scope of this project:

| Forbidden Claim | Evidence-Based Reason / Rebuttal |
|:---|:---|
| "The detector achieves universal >95% accuracy across all domains." | Disproven by Task 4: cross-dataset transfer suffers 52% to 95% F1 degradation with false alarm rates up to 68.6% across unadapted domains. |
| "The system is fully production-ready for arbitrary enterprise networks." | Production deployment is strictly unvalidated; enforcement has been tested only within isolated Linux network namespaces (`10.200.1.0/24`). |
| "The DQN policy achieves the pre-registered practical effectiveness threshold." | Statistically significant improvement was achieved (+11.29% and +14.10%, $p < 0.001$), but the pre-registered practical effect-size target ($\ge 15.0\%$) was **NOT MET**. |
| "SHAP shows feature X physically causes network intrusions." | Model feature attribution is associative relative to background expectation; attribution is not physical causality. |
| "Live detection accuracy is validated on unlabelled network traffic." | Ground truth labels are unavailable for live unmanaged network streams; live telemetry measures flow counts, latency, and action distributions (§64). |
| "Adding more features always improves intrusion detection." | Disproven by D-002: R10 captures sufficient variance; adding features introduces redundancy and cross-dataset incompatibility. |
| "Phase 3K proved zero packet loss under all conditions." | In the 50,000 pps overload tier, 1,808 packets were intentionally shed via application backpressure. |
| "Memory monitoring mathematically proves absence of all possible leaks." | Bounded RSS growth of 12.05 MiB was observed over 10,000 flows, but unbounded operational timeframes were not evaluated. |
| "Autonomous response was executed on the host network." | The host network was cryptographically verified to have zero mutations; all response mutations occurred strictly within virtual namespaces. |
