# HISTORICAL RESULTS

This file exists to **quarantine** numbers reported by the previous XRL-IDARS repository.

## The rule

> Historical numbers are **not** results of this repository.
> They are **not** evidence. They are **not** proof of reproducibility.
> They may only be used as (a) a hypothesis to re-test, or (b) a comparison point once
> this repository produces its own value from its own artifacts.

Every entry carries the label **`historical — not reproduced yet`**.

## What the historical repository reported

The previous project reported RF / LSTM / Fusion numbers on CICIDS2017, CSE-CIC-IDS2018
and UNSW-NB15, along with cross-dataset transfer directions and a DQN comparison against
baselines. **The specific values are deliberately not transcribed here.** Transcribing them
would invite them to be copied into the new README as if they were reproduced.

If a specific historical value is needed for comparison, a Decision/Experiment entry must
record it explicitly with its source file in the old repository, and mark where it came from.

## Reproduction tracking

When a new experiment attempts to reproduce a historical finding, record it here:

| Historical finding (description) | New experiment | Historical value | New value | Difference | Investigation | Status |
| --- | --- | --- | --- | --- | --- | --- |
| *(none attempted yet)* | — | — | — | — | — | ⬜ |

Status values: `NOT_ATTEMPTED` · `REPRODUCED` · `REPRODUCED_WITH_DIFFERENCE` · `NOT_REPRODUCED`

## Never

- Never silently replace a historical value with a new one.
- Never report a historical value as this project's result.
- Never delete a historical finding that failed to reproduce — the failure is the finding.
