# XRL-IDARS Frontend Dashboard

**Demonstration & Viva Visual Interface for Explainable Intrusion Detection and Autonomous Response**

This frontend is a lightweight, read-only visualization dashboard designed for demonstration, evaluation walkthroughs, and viva examination defense of the XRL-IDARS platform.

---

## 1. Purpose & Scope

- **Demonstration UI Only**: Visualizes the real flow-level outputs, canonical R10 features, continuous threat scores, and threshold evaluations generated by the XRL-IDARS PCAP replay pipeline.
- **No Direct Backend / API**: The frontend intentionally operates without an active HTTP backend daemon or microservices. It ingests machine-readable JSON artifacts directly from `results/demo/replay_summary.json` (or a static fallback fixture `src/data/demoData.ts`).
- **Zero Live Network Mutation**: The dashboard **never** interacts with host network interfaces, iptables, nftables, routing tables, or real packets. All autonomous response actions shown in the UI are visual records of offline policy evaluations or historical transactions.

---

## 2. Technology Stack

- **Framework**: React 18
- **Build Tool**: Vite 6
- **Language**: TypeScript 5.6
- **Styling**: Pure modern CSS (dark-themed, SOC / cybersecurity aesthetic)
- **Zero Heavy Frameworks**: No heavy UI component libraries or graphing runtime dependencies; uses native reactive SVG rendering for high-performance chart visualization.

## 3. Data Source & Field Provenance

### Primary Data Source
```text
results/demo/replay_summary.json
```
This JSON file is generated by executing the real end-to-end replay engine:
```bash
.venv/bin/python scripts/demo/run_replay_demo.py
```
A synchronized copy of this file resides in `public/replay_summary.json` so that the browser can fetch it locally.

### Real vs Unavailable Fields

| Field / Component | Status in Replay Summary | Description |
|:---|:---|:---|
| **Packets Processed** | **REAL** | Ingested packet count from `data/demo/sample_traffic.pcap` (42 packets) |
| **Flows Detected** | **REAL** | 6 bidirectional flows reconstructed under the D-006 policy |
| **Endpoints & Ports** | **REAL** | IPv4 addresses and TCP/UDP ports extracted directly from PCAP headers |
| **Protocol** | **REAL** | Transport layer protocol (TCP, UDP) |
| **Flow Duration** | **REAL** | Microsecond/millisecond active duration |
| **Canonical R10 Features** | **REAL** | Exact 10-feature vector (`flow_duration_ms`, `flow_packets_per_s`, `flow_bytes_per_s`, `packet_length_mean`, `packet_length_std`, `syn_count`, `ack_count`, `rst_count`, `fin_count`, `syn_ack_ratio`) computed with mathematical parity ($\text{atol} \le 10^{-4}$) |
| **Threat Score ($S_t$)** | **REAL** | Continuous probability output from the trained Random Forest model (`results/experiments/EXP-P1-CIC2017-R10-001/random_forest.joblib`) |
| **Threshold Verdicts** | **REAL** | Classifications evaluated at $\tau=0.50$ (Research Baseline) and $\tau=0.40$ (Operational Candidate) |
| **DQN Mitigation Actions** | *UNAVAILABLE in replay artifact* | Evaluated in the separate Phase 2 reinforcement learning environment and Phase 3 transaction harness |
| **Per-Flow SHAP Vectors** | *UNAVAILABLE in replay artifact* | Available in research explainability pipelines (`results/phase2/EXP-P2E-EXPLAINABILITY-001/`); indicated clearly in the inspection drawer |

## 4. Setup and Execution

### Prerequisites
- Node.js $\ge 18$ (verified with Node v24.21.0)
- npm $\ge 9$ (verified with npm 11.19.0)

### Installation
```bash
cd services/frontend
npm install
```

### Development Server
```bash
npm run dev
```
Opens Vite development server on `http://localhost:3000` (or the next available port).

### Production Build
```bash
npm run build
```
Compiles TypeScript and bundles production assets into `dist/`.

### Preview Production Build
```bash
npm run preview
```
Serves the compiled production build locally for testing and demonstration.

## 5. UI Features

1. **Top Status Strip**: Displays system operational mode (`PCAP REPLAY / DEMO`), active model (`Random Forest`), feature contract (`R10`), research baseline threshold ($0.50$), and operational candidate threshold ($0.40$).
2. **System Pipeline Diagram**: Visual trace from packet ingestion through feature extraction, detection, response policy, safety gate, and audit logging.
3. **KPI Cards**: Summary metrics showing packets processed, flows detected, attack flows, benign flows, average threat score, and benchmark test F1 score.
4. **Interactive Flow Table**: Real-time filtering by protocol (TCP/UDP), verdict (BENIGN/ATTACK), free-text search (IP, port, protocol, flow ID), and multi-column sorting.
5. **Threat Score Distribution Chart**: Custom SVG chart plotting continuous threat scores across flows against the $0.50$ and $0.40$ decision boundaries.
6. **Network Topology Summary**: Unique source and destination IP inventories, protocol percentages, and aggregated traffic volume.
7. **Flow Detail Drawer**: In-depth inspection panel revealing all 10 canonical R10 features, threshold comparison, DQN mitigation status, and explainability notes.
8. **Demo Data Toggle**: Allows switching between real loaded JSON and the built-in static fallback dataset (`src/data/demoData.ts`).
